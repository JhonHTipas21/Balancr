# Contributing to Balancr

We welcome contributions to Balancr! Our goal is to make autonomous payment reconciliation accessible and reliable.

## Code Style

* We use standard Python PEP 8 conventions.
* Type hints are required for all method signatures.
* Ensure all functions and classes are documented with docstrings.
* Run `pytest` before submitting a pull request to guarantee no regressions.

## Getting Started

1. Fork the repository.
2. Create a feature branch (`git checkout -b feature/my-feature`).
3. Make your changes and commit them with descriptive messages.
4. Push your branch and open a Pull Request.

Thank you for contributing to Balancr!
